# DeepThink v1.9.0 发布说明

> 发布日期：2026-11-06 ｜ 主题：**端上自治（On-Device）**——DeepThink 整体跑进 Android 手机，外加移动端导航的两处硬修复。
>
> 自 v1.8.3 起共 7 个 commit（1 个功能 + 6 个修复）。Schema 无变更；API 仅加性新增；无破坏性变更。

---

## 📱 Android 端上自治运行（Phase 0+1）（2928001）

DeepThink 从此可以**不依赖任何自建/远程 server**，整体运行在一部 arm64 Android 手机里：
Termux 承载后端运行时（Node 服务监听本机 127.0.0.1），Android 壳 app 自动发现并连接本机服务，
对话 / 文件 / 记忆 / 定时任务 / Skills / IM 等平台能力全部端上自治（Agent 推理仍走云端 LLM API——
"不连 server" ≠ 离线）。

### 能力变化

| | 旧 | 新 |
|---|---|---|
| Android app | 纯 WebView 壳，必须手动填 server URL | **零配置**：自动探测本机服务（`/api/health`，9898 + 9890–9900 区间）直接进入；未发现时给 Termux 启动引导页；保留远程 URL 手动模式 |
| 后端部署 | 只有服务器 / 桌面版 | **Termux 一键安装**（`android/termux/install.sh`）：依赖安装 → npm 依赖（better-sqlite3 设备端编译）→ claude CLI glibc 兼容（patchelf 重写 interpreter，配方来自 claude-code-android）→ 自检汇总；`start/stop/status.sh` 启停守护（wake-lock + 健康探针） |
| 运行时分发 | — | **`make android-payload`** 打包管线：五件套（backend / web-dist / agent-runner / config / skills）22MB tar.gz + SHA256 + 清单校验，node_modules 设备端安装（不随包分发） |
| 功能降级 | — | 无 Docker 自动降级一级路径（host 执行模式）：沙箱代码执行 / 浏览器自动化 / Web 终端不可用（app 内一次性降级提示条），其余功能完整 |

### 顺带修复：pty-worker.cjs 打包丢失（影响桌面版与 Android payload 同源）

`src/terminal-manager.ts` 的 `PTY_WORKER_PATH` 旧写法解析 `dist/../src/pty-worker.cjs`，打包部署
（desktop extraResources / android payload）不含 `src/` → PTY 静默降级 pipe 模式。改为与入口同级
（dev `src/` 与 prod `dist/` 同构）并登记进 `scripts/copy-runtime-assets.cjs`，与 `eval-schema.sql`
同类事故同款修法（见 docs/issues/2026-09-29）。

## 🔧 修复（6 项）

- **移动端底部导航菜单无法横向滑动、屏幕外菜单不可达**（6d25de8）——10 个固定宽度菜单项（≈554px）
  溢出窄屏视口（360–430px）且无横滑能力，右侧入口（评测中心/运行监控/网盘/开放平台/设置）看不见也点不到。
  修复：胶囊 `max-content + max-width:100% + overflow-x:auto`（避开 flex 裸居中的溢出不可达陷阱）+
  scroll-snap 吸附 + 激活项自动滚入视口中央。模拟器实测横滑前后各显示 5 项、全部可达。
  复盘：docs/issues/2026-11-06-mobile-bottom-nav-no-scroll.md
- **Android 壳远程模式导航被劫持到外部浏览器**（7e53ec9）——`shouldOverrideUrlLoading` 允许清单
  只认 loopback，远程主机（如 `10.0.2.2`/内网域名）的初始加载被误判外链发 `ACTION_VIEW` 拉起 Chrome。
  修复为「loopback 或已连接服务器同主机」留在 WebView 内。
- **Android 壳设置页单选按钮互斥失效**（7e53ec9）——RadioButton 未包 RadioGroup，本地/远程可同时选中。
- **Android 壳设置页修改远程 URL 返回后不即时生效**（df85655）——onResume 增加目标 URL 变更检测。
- **工作区指定本机目录后 Agent 仍跑在默认目录**（15cea2f）——custom_cwd 后续修复。
- **Agent 对话产物渲染 404**（3f93e74）与 **Windows 打包 npm rebuild 被运行实例锁死 better_sqlite3.node**
  （804fdda）——v1.8.3 后的两个稳定性修复随版发布。

## 📦 安装与升级

```bash
# 服务器 / 桌面版：常规升级即可
git pull && make build && make start

# Android 端上运行（详见 android/README.md）
make build && make android-payload          # 产出 dist-android/*.tar.gz
# 手机 Termux：解包 → bash termux/install.sh → bash termux/start.sh
# 壳 app：android/ 下 ./gradlew :app:assembleRelease（或下载发布 APK）
```
