# DeepThink v1.8.3 发布说明

> 自托管的多用户本地 AI Agent Loop Engineering 系统（支持桌面端 + 浏览器 + 移动端）
> Powered By AI Genius Institute，AI 光剑

发布日期：2026-10-29

v1.8.3 是一个**能力补齐**版本：把「选择用户本机目录作为工作区」从宿主机模式半成品，
补齐为**两种执行模式通用、创建后可改**的一等能力——容器模式下 Agent 也能直接在
本机真实项目目录（如 `~/projects/my-app`）上工作，不再需要「复制本地目录」的
一次性副本。本版本共 **1 个 commit**（自 v1.8.2，`ee47924`，21 个文件 +1277/−135），
无 Schema 变更、无破坏性 API 变更。

---

## 📂 工作区目录支持选择用户本机目录（custom_cwd）

### 能力变化

| | 旧 | 新 |
|---|---|---|
| 容器模式工作区 | 固定 `data/groups/{folder}` → 挂载到 `/workspace/group` | 可指向任意（白名单内）本机目录，bind-mount 到 `/workspace/group` |
| 设置时机 | 仅创建时（且仅 host 模式） | 创建时 + **创建后随时修改 / 恢复默认**（`PATCH /api/groups/:jid`） |
| 权限 | admin 专属 | 不变（admin 专属，member 隔离边界不放宽） |

- **创建对话框新增「使用本机目录」来源**：与「复制本地目录」（`init_source_path`）互斥——
  一个是「以本机目录为工作区」，一个是「把本机目录拷贝进平台工作区」，语义不同不许混用。
- **工作区菜单新增「工作目录」管理对话框**（`WorkspaceDirDialog`）：查看当前工作目录、
  换目录、恢复默认；重建工作区时明确提示**本机目录里的文件不会被删除**（平台只清理
  自己托管的 `data/groups/{folder}`）。
- **admin 主容器 `web:main` 从此可配 `custom_cwd`**——系统设置「禁用 DeepThink 记忆层」
  的前置校验要求先给 `web:main` 配好工作目录，此前该前置条件实际不可满足，现已打通。

### 安全边界（不放宽）

校验收敛到 **`src/workspace-root.ts` 一个模块**，三处消费同源：

1. **创建 / 修改时** `validateCustomCwd`：必须绝对路径 + 目录已存在 + 在
   `config/mount-allowlist.json` 挂载白名单内 + 不命中敏感路径屏蔽模式（如 `.ssh`）+
   **不允许指向平台数据目录（DATA_DIR 内）**——防止 Agent 把 `logs/`、`sessions/`、
   `data/db` 之类平台运行时数据当工作区搅乱。
2. **运行时二次校验** `checkCustomCwdAllowedAtRuntime`：防 DB 注入 / 白名单事后收紧，
   启动容器前再查一遍，不过就拒绝执行。
3. **容器挂载** `buildVolumeMounts`：`customCwd` 作为 `/workspace/group` 挂载源，
   无 `customCwd` 时回落 `GROUPS_DIR`。

### 消费点统一（顺带修掉一个隐性 bug）

工作区根目录解析规则（`customCwd || data/groups/{folder}`）此前在后端散落 **5 处**
重复实现，且 `src/script-runner.ts` 直接硬取 `data/groups/{folder}`——**自定义工作区的
定时脚本任务 cwd 落在错误目录**。本次全部收敛到 `resolveWorkspaceRoot` 单一来源，
script-runner / files 面板 / workspace-config 统一走它。

### 前端

- 创建对话框「使用本机目录」来源（目录选择器沿用 `DirectoryBrowser`）
- 工作区菜单「工作目录」管理对话框（`WorkspaceDirDialog`，查看 / 修改 / 恢复默认）
- 重建工作区确认框新增「本机目录文件不删除」提示
- 群组条目展示当前工作目录来源

## 📦 安装与升级

- **Windows**：下载 `DeepThink-Setup-1.8.3.exe` 覆盖安装；已装旧版本的用户会**自动静默更新**
  （后台下载 → 备份配置到 `%APPDATA%\DeepThink\backups` → 重启安装）。
- **macOS / Linux**：对应 `.dmg` / `.AppImage`。
- 数据目录（`%APPDATA%\DeepThink\data`）不受升级影响；`registered_groups` 无 Schema 变更，
  旧数据直接沿用。
- 桌面版版本号 `1.8.3`（`desktop/package.json`），与 tag / 发布线同号，
  本地 `scripts/pack-win.ps1 -Version 1.8.3` 打包同号。
