# DeepThink v1.8.1 发布说明

> 自托管的多用户本地 AI Agent Loop Engineering 系统（支持桌面端 + 浏览器 + 移动端）
> Powered By AI Genius Institute，AI 光剑

发布日期：2026-10-28

v1.8.1 是一个**修复与桌面体验收口**版本，没有新模块，但关掉了两个用户每天都会撞上的问题：
**Agent Studio「AI 生成」永远报「provider 可能不可用或超时」**，以及**桌面端一启动就弹「发现新版本」对话框**。
外加 Windows 平台的打包/运维脚本收口，让 Windows 用户不再依赖 make 与手工排查。

本版本共 **12 个 commit**（自 v1.8.0），无 Schema 变更、无破坏性 API 变更。

## 🐞 修复一：Agent Studio「AI 生成」误报失败（其实每次都生成成功了）

现象是点「AI 生成」后**恰好 8 秒**弹 `AI 生成失败（provider 可能不可用或超时）`，而 provider 自检正常、
Skills 的 AI 生成也正常。实测后端生成链路完全健康：一次真实生成 **22~30 秒**。

- **根因**：前端 `api.post` 未传超时，落进 `api/client.ts` 的默认 **8s**；后端 LLM 预算是 **90s**
  （`src/agent-ai.ts`）。`8s < 22s`，请求永远不可能在前端超时前返回——与 provider 无关。
  同类的 Skills AI 生成都传了 150s，唯独 agents-paas 两处漏了。
- **连带发现第二个缺陷**：模型约 **1/6** 概率在 JSON 字符串值里写未转义引号（如
  `清单填写"未发现问题"`），`JSON.parse` 失败 → 502。此前 502 **不落任何日志**，
  前端又把错误吞成笼统文案，线上无从定位。
- **修复**：两个 AI 调用显式传 150s 超时；解析失败**重试一次**（空响应/超时不重试，避免把
  等待翻倍挤掉预算）；toast 改为显示后端真实原因；502 与解析重试都落日志。
- **验收**：隔离实例端到端 3/3 返回 `HTTP=200`（23.5~26.0s）；`curl --max-time 8` 复现
  旧前端 abort（exit 28）；新增 11 个回归测试锁「超时 ≥ 后端预算」「错误不得吞掉」「重试语义」。

## 🔇 修复二：桌面版自动更新改为全静默

打开桌面程序会弹「发现新版本 DeepThink x.y.z 已发布，正在后台下载…」对话框。按产品期望
（**不要弹出来，有更新直接后台静默更新**）：

- 删除「发现新版本」告知型对话框：后台静默下载；
- 备份失败也不再弹「是否仍要安装」询问框：照常安装并记日志（`userData` 在
  `%APPDATA%\DeepThink`、NSIS 安装不覆盖它，备份只是兜底；原实现意图就是 *don't block the update*）；
- **安装时机不变**（用户选定）：下载完成后自动备份配置到 `backups/` 并**自动重启安装**；
- **静默 ≠ 无痕**：`update-available` / `update-downloaded` / 备份成败 / 错误全部写入
  `logs/main.log`，"程序为什么自己重启了"可查。

## 🐞 修复三：托盘图标空白（「显示隐藏的图标」面板里没有图标）

Windows 任务栏溢出面板里 DeepThink 一项没有图标。根因是**托盘图标资产从未生成过**：
`generate-tray-icons.sh` 需要 ImageMagick、缺失时静默跳过，而打包/CI 流程从不调用它；
`nativeImage.createFromPath` 在文件缺失时返回**空图**（不抛异常），托盘项就成了空白。

- **修复**：图标按「平台首选 `tray.*` → 应用图标 `icon.*` → 空图」回退。`icon.ico`/`icon.png`
  随包必有，零构建依赖，三平台同一处修好；macOS 模板图只对平台首选生效（彩色回退图标
  设模板会变黑剪影）。
- **诊断手法**：`grep -ao '"tray\.ico":' app.asar` 直接看包内文件清单，比猜打包配置快。

## 🪟 Windows 平台收口

- **`scripts/pack-win.ps1`**：免 make 的 Windows 桌面一键打包（依赖安装 → shared/ 同步 →
  后端/前端/agent-runner/Electron 壳编译 → 内置 Node ABI 重建校验 → NSIS 出包）。
- **打包自动提升版本号**：默认每次 +1 patch（`-Version` 显式指定 / `-NoBump` 保持），
  否则同版本覆盖安装时 electron-updater 识别不出新版本。
- **Windows 运维脚本**：`rebuild-restart.ps1` / `stop-prod.ps1` / 看门狗修复（静默退出、
  日志乱码、增量编译误判）。
- **Windows 平台缺陷修复**：`.cmd`/`.bat` 启动的 stdio MCP server 连接失败（spawn EINVAL）；
  `desktop-build-deps` 依赖顺序导致 fresh 机器构建失败；`shared/web-search.ts` 的
  `execFile` 回调类型不兼容导致 agent-runner 编译失败。
- **WebSearch 浏览器搜索后端**：免 API Key 的联网搜索后端（`shared/web-search.ts` 单向真相源，
  宿主自检与容器实际调用共用同一实现）。

## 📦 安装与升级

- **Windows**：下载 `DeepThink-Setup-1.8.1.exe` 覆盖安装；已装旧版本的用户会**自动静默更新**
  （后台下载 → 备份配置到 `%APPDATA%\DeepThink\backups` → 重启安装）。
- **macOS / Linux**：对应 `.dmg` / `.AppImage`。
- 升级前的配置备份保留 3 份以内可自行清理；数据目录（`%APPDATA%\DeepThink\data`）不受升级影响。
