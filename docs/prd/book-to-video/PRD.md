## 1. 产品背景与目标

### 1.1 问题陈述

知识传播正在从「长文阅读」向「短视频消费」迁移。但现有方案有三大痛点：

1. **人工制作成本高**：一条 2 分钟知识类短视频需要文案策划 + 配音 + 剪辑，耗时 4-8 小时
2. **个性化缺失**：模板化 AI 视频千篇一律，不能克隆用户/作者本人音色
3. **隐私泄露风险**：市面大多数服务要求上传整本原书到云端

### 1.2 目标用户

- **读书博主**：批量生产书评短视频，日更不重样
- **出版机构**：新书宣传物料自动化生成
- **知识付费创作者**：将专栏/课程文稿转短视频引流
- **个人学习者**：读完一本书后生成「读书笔记视频」分享

### 1.3 核心价值主张

> "任意一本书，2 分钟，你的声音，双语字幕，一键出片。"

- **全自动化**：上传 PDF/EPUB → 等待 → 下载 MP4
- **声音克隆**：用户录制 5-15 秒参考音频，视频用本人音色旁白
- **隐私优先**：云端只上传章节摘录，不全本外传
- **企业级质量**：ASS 双语字幕、Ken Burns 动效、响度归一化

## 3. 非功能需求

| 需求 | 目标 | 实现 |
|---|---|---|
| 隐私安全 | 不整本外传 | 上云仅章节摘录（≤6000 字/块） |
| 声音授权 | 合规 | 片尾 AI 合成标识 + 用户确认 |
| 性能 | ≤ 5 分钟/本 | 云端 LLM ≈ 2-3 分钟 + TTS ≈ 1-2 分钟 |
| 可插拔 | 模型/引擎可替换 | OpenAI 兼容协议 + 引擎抽象层 |
| 输出质量 | 120.0s ± 0.5s | 音频驱动时间轴 + atempo 微调 |

## 4. 用户故事

### US1：读书博主日更

> 作为一名读书博主，我希望上传一本 EPUB 书，用我自己的声音生成一条 2 分钟的书评视频，这样我可以每天发布不重样的内容。

验收条件：
- Given 一个 EPUB 文件 + 5s 参考音频
- When 运行 `python pipeline.py --book book.epub --voice-id my_voice`
- Then 生成 120s MP4，含我的声音旁白 + 中英字幕 + 动态画面

### US2：隐私敏感用户

> 作为一名隐私敏感的作者，我希望云端只看到我的书的章节要点而非全文，但生成质量不打折扣。

验收条件：
- Given 一本 30 万字的书
- When 运行 pipeline
- Then 云端 API 调用负载 ≤ 12 万字符（全书 40%）

### US3：无 GPU 用户

> 作为一名仅有 CPU 笔记本的用户，我希望仍然能生成视频（哪怕语音不是我的克隆音色）。

验收条件：
- Given 没有 GPU 且 CosyVoice 未安装
- When 运行 pipeline
- Then 自动降级为 DashScope TTS，仍生成完整 MP4
