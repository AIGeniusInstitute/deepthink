2. Bug 根因与修复

Bug 1: Agent 对话无中间流式输出

根因：src/index.ts 中 processAgentConversation 的 wrappedOnOutput 回调在分布式模式下缺少 persistTraceNodeFromStreamEvent 调用，导致 trace node 未持久化。

// 修复前（仅 broadcastStreamEvent） broadcastStreamEvent(chatJid, output.streamEvent, agentId); // 修复后（增加 trace node 持久化） persistTraceNodeFromStreamEvent(virtualChatJid, output.streamEvent); broadcastStreamEvent(chatJid, output.streamEvent, agentId);

Bug 2: 新建 Agent 会话 Tab 无响应

根因：processAgentConversation 缺少分布式调度检查 isRedisConnected() && hasDistributedRunners()，在 K8s 环境下未将任务发布到 agent-runner pods。

// 修复前：直接调用 runContainerAgent / runHostAgent（K8s 不存在） // 修复后：增加分布式分发路径 if (isRedisConnected() && await hasDistributedRunners()) { // 构建 taskInput → 注册 distributedOutputHandlers → publishAgentTask } else { // 回退到本地执行 }
