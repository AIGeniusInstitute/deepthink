Bugs Fixed

createGroupSeat INSERT contained updated_at but DB table lacked the column
The group_seats table originally had no updated_at column. Removed updated_at from the INSERT parameter list in db.ts.
createGroupMessage was missing created_at value in parameter list
The INSERT statement expected a created_at value but the calling code did not supply it, causing a SQL constraint error. Added new Date().toISOString() to the parameter list.
Migration DDL updated: group_seats now includes updated_at TEXT
Applied ALTER TABLE group_seats ADD COLUMN IF NOT EXISTS updated_at TEXT to fix the mismatch between application code and schema. The column is now present in both SQLite and PostgreSQL backends.
Frontend API types mismatched backend response shapes
The TypeScript types used in api.ts assumed different JSON field names than what seatToJson and msgToJson actually return. Rewrote all API types to match the exact backend response shapes (e.g. speak_policy vs speakPolicy, seat_label vs label).
updateAgentGroup used PUT but backend only supports PATCH
The frontend api.ts function made a PUT request to /api/agent-groups/:id, but the Hono route handler only registered a router.patch(). Changed the frontend call to use PATCH.
CreateGroupDialog used wrong field names for seat config
The dialog was sending seatLabel, seatType, and speakPolicy: "manual", none of which are valid per the backend schema. Removed these fields; the dialog now sends rolePrompt and uses correct speakPolicy enum values ("auto" / "manual" / "trigger").
