三、Bug 修复记录

Bug #1: includeInactive 查询参数不兼容 `true` 值

严重度：中 | 发现阶段：API E2E 测试 TC-01.7 | 修复状态：✅ 已修复

现象：GET /api/staff/employees?includeInactive=true 不返回已删除员工，仅 =1 生效。

根因：staff-employees.ts:27 硬编码 === '1'，不接受 REST 惯例 'true'。

- const includeInactive = c.req.query('includeInactive') === '1';
+ const q = c.req.query('includeInactive');
+ const includeInactive = q === '1' || q === 'true';

验证：修复后 ?includeInactive=true 正确返回 inactive 员工（TC-01.7 PASS）。

Issue 文档：docs/issues/2026-09-11-includeInactive-query-param-bug.md
