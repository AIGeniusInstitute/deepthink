**根因**: PG BIGINT 列在 node-postgres 驱动中作为字符串返回，`!!"0" === true` - **修复**: - 代码: `!!row.must_change_password` → `!!(Number(row.must_change_password))` (src/db.ts ×2) - DB: `ALTER TABLE users ALTER COLUMN must_change_password TYPE integer` - **状态**: ✅ 已修复 ### BUG-2: Ingress Controller v1.12.2 镜像不可用 - **根因**: kind 节点无公网出网, registry.k8s.io 不可达 - **修复**: 使用预加载的 v1.11.2 镜像, 移除 admission webhook - **状态**: ✅ 已修复 ### BUG-3: etcd 镜像不可用 - **根因**: milvus etcd 引用 registry.k8s.io/etcd:3.5.21-0 不在节点上 - **修复**: 从 mirror pull bitnami/etcd → tag → kind load - **状态**: ✅ 已修复 ## 测试总结 | 指标 | 值 | |------|-----| | 总测试用例 | 28 | | 通过 | 28 | | 失败 | 0 | | 通过率 | 100% | | Bug 发现/修复 | 3/3 | | 部署总服务 | 9 | | 部署总 Pod | 14 (11 running + 3 completed jobs) | | 持久化卷 | 7 PVCs (总计 218Gi) | ## 访问入口 -
