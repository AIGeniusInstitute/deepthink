DeepThink · @deepthink/agent-sdk

Agent SDK 用户手册

把 Agent Studio 导出的 AgentBundle 嵌入任意 Node.js 应用——完整 agentloop（多轮会话、流式、续接）+ skills + MCP 工具能力包，无需部署 DeepThink 平台。

Node.js ≥ 22 T0 核心 agentloop T1 skills + MCP T2 平台工具（M1） SDK 0.1.x

概览

SDK 做三件事：加载 AgentBundle（你在 Agent Studio 导出的自包含发布物）、在本进程里跑 agentloop（会话、流式、resume）、暴露 能力包（skills、MCP 工具、自包含工具）。运行全程不接触 DeepThink 平台的任何进程、端口或数据库——依赖面只有本包和 LLM API。

能力分级

层级能力状态
T0 agentloop：流式、多轮会话、跨进程 resume、自包含工具（web_fetch / web_search / disk_* / memory_*） 本版本包含
T1 + bundle 内联 skills（自动装配）+ MCP servers（stdio / http / sse） 本版本包含
T2 + 平台宿主工具（send_message / schedule_task / sandbox_* 等，以回调形式接入） 规划中（M1）
设计原则 未实现的能力不会注册为工具——你不会遇到「工具存在但调用报错」。bundle 没声明的 skill / MCP 也一律不可见（白名单收敛）。

安装

bash
npm install @deepthink/agent-sdk
# 或安装本地 tarball
npm install ./deepthink-agent-sdk-0.1.0.tgz

环境要求

  • Node.js ≥ 22（SDK 无原生模块依赖，Windows / macOS / Linux 通用）。
  • 一个 Anthropic 兼容的 LLM API（官方 Anthropic 或兼容代理端点均可）。
安装后自检 npm 的 allow-scripts 策略可能拦截 @anthropic-ai/claude-code 的 postinstall，留下几百字节的 stub，运行时报 ENOEXEC。如遇「claude CLI 不是可执行文件」类错误，允许该包的 install 脚本后重装：npm rebuild @anthropic-ai/claude-code。

5 分钟上手

  1. 导出 bundle
    在 Agent Studio 打开你的 Agent → 详情页 → 「导出 SDK Bundle」，得到 my-agent.bundle.zip。
  2. 配置凭据
    export ANTHROPIC_API_KEY=sk-…（可选：ANTHROPIC_BASE_URL 指向兼容代理）。
  3. 跑起来
    把下面的代码存成 app.mjs，node app.mjs。
app.mjs
import { Agent, createToolsServer } from '@deepthink/agent-sdk';

const workspace = './data/my-agent';

const agent = await Agent.fromBundle('./my-agent.bundle.zip', {
  credentials: {
    apiKey: process.env.ANTHROPIC_API_KEY,
    baseUrl: process.env.ANTHROPIC_BASE_URL,   // 可选
    model: process.env.ANTHROPIC_MODEL,         // 可选，覆盖 bundle 里的模型名
  },
  workspace,
  // bundle 若引用了 ${ENV:XXX} 密钥，在这里提供（或用环境变量）
  secrets: { MY_TOKEN: process.env.MY_TOKEN },
  onEvent: (e) => {
    if (e.eventType === 'text_delta') process.stdout.write(e.text ?? '');
    else if (e.eventType === 'tool_use_start') console.log(`\n[tool] ${e.toolName}`);
    else if (e.eventType === 'status') console.log(`\n[${e.summary}]`);
  },
  toolsServer: createToolsServer({ workspace }),
});

// 一次性调用
const r = await agent.run('用一句话介绍你自己');
console.log('\nusage:', r.usage);

// 多轮会话
const session = await agent.start({ prompt: '记住：项目代号是「灯塔」' });
await session.wait();
const r2 = await session.send('项目代号是什么？只回答代号。');
console.log(r2.text);   // → 灯塔
await session.close();
这就够了 同一 workspace 再跑一次脚本，对话会从上次继续（自动 resume）。想开新对话：agent.resetSession()。

AgentBundle

bundle 是自包含的发布物——zip 或目录，结构如下：

bundle 结构
my-agent.bundle/
  manifest.json          # schema、能力声明、${ENV:...} 密钥引用、contentHash
  agent.json             # agent 定义（prompt / model / temperature / 校验策略）
  prompts/system.md      # 最终 system prompt（导出时固化，所见即所得）
  skills/{id}/SKILL.md   # skill 本体内联（含同目录其他文件）
  mcp/servers.json       # MCP 配置（env / header 值全部脱敏为 ${ENV:...}）

密钥不进包

导出时 MCP 的 env 与 headers 值全部替换为 ${ENV:NAME} 引用，明文永远不会出现在 bundle 里。加载时按 secrets 选项优先、环境变量兜底的顺序解析：

ts
const agent = await Agent.fromBundle(bundlePath, {
  workspace,
  secrets: { MY_TOKEN: 'value-a' },   // 优先
  // 未提供的引用回落到 process.env.MY_TOKEN
});

manifest 里标记为 optional 的引用缺失不阻塞；必需引用缺失会拒绝加载并列出全部缺失项（见「错误与排查」）。

完整性校验

manifest 的 contentHash 覆盖除 manifest.json 外的全部文件（确定性哈希，与打包顺序无关）。加载时逐字节校验，任何篡改都会被拒绝。

仅限调试 Agent.fromBundle(path, { skipHashCheck: true }) 可跳过校验。不要在生产路径上使用——它关闭的正是 bundle 的防篡改保障。

API 参考

Agent.fromBundle(path, options)

加载 bundle（zip 或目录）并装配运行时。校验失败、密钥缺失会抛错。

选项类型说明
workspacestring（必填）工作区目录。会话、记忆、skill 装配、agent 产物都在这里。
credentials{ apiKey?, baseUrl?, model? }LLM 凭据。model 覆盖 bundle 的模型名（兼容代理端点常用）。
onEvent(e: StreamEvent) => void流式事件回调，见「流式事件」。
secretsRecord<string, string>${ENV:...} 密钥表，优先于环境变量。
timeoutMsnumber单回合超时，默认 30 分钟。
permissionModestring工具权限模式，默认 bypassPermissions（headless 无法交互授权；需要收紧时传 default 等）。
toolsServerSDK MCP server自包含工具包：createToolsServer({ workspace })。
extraMcpServersRecord<string, cfg>在 bundle 声明之外叠加 MCP server。
skipHashCheckboolean跳过 contentHash 校验，仅限调试。

agent.run(prompt, opts?)

一次性调用，返回 RunResult：

ts
interface RunResult {
  text: string;                 // 最终回复
  sessionId: string | null;     // SDK 会话 id（用于续接）
  usage?: Record<string, number>; // token 用量
  error?: string;               // 非 success 时的原因（不抛异常）
}

agent.start(opts) → Session

开启会话并发起首回合。自动续接同 workspace 的历史会话。opts 支持 prompt、images（base64 图片数组）、以及按回合覆盖的 model / maxTurns / temperature。

方法说明
session.send(prompt | opts)发送回合，返回本回合 RunResult。排队执行：当前回合结束后自动续跑，消息不丢。
session.wait()等待最近回合完成。
session.interrupt()中断当前回合（长任务刹车）。排队消息保留，后续继续处理。
session.close()关闭会话，清空未执行队列。
agent.resetSession()清除续接状态，下次 start 开新对话。

loadBundle(path, opts?)

底层入口：只解包 + 校验 + 解析密钥，不建会话。返回 { manifest, agent, systemPrompt, skills, mcpServers }，适合自定义装配。

流式事件

onEvent 收到的 StreamEvent 与 DeepThink 平台 Web 流式卡片同一类型，常用事件：

eventType含义常用字段
init回合开始sessionId
text_delta回复文本增量（拼接即全文）text
thinking_delta思考过程增量text
tool_use_start工具开始调用toolName、toolInputSummary
tool_use_end工具调用结束toolName、toolUseId
status回合终态（含 usage）summary、usage
ts · 终端流式渲染
onEvent: (e) => {
  switch (e.eventType) {
    case 'text_delta':    process.stdout.write(e.text ?? ''); break;
    case 'tool_use_start': console.log(`\n[tool] ${e.toolName} ${e.toolInputSummary ?? ''}`); break;
    case 'status':        console.log(`\n[${e.summary}]`, e.usage); break;
  }
}

自包含工具

通过 createToolsServer({ workspace, webSearch?, memoryDir? }) 注册，零 IPC、纯本地：

工具作用
web_fetch抓取 URL 并转 Markdown（charset 嗅探，含 GB18030）
web_search联网搜索；未配凭据时返回明确的降级提示（不静默）
disk_list / disk_read / disk_write / disk_deleteworkspace 内文件操作；路径穿越会被拒绝
memory_append / memory_search / memory_get日期记忆（默认 {workspace}/memory/）

启用搜索需要提供 provider 凭据：

ts
toolsServer: createToolsServer({
  workspace,
  webSearch: { provider: 'zhipu', apiKey: process.env.WEB_SEARCH_API_KEY },
})

Skills 与 MCP

Skills

bundle 内联的 skill 在加载时自动装配到 {workspace}/.claude/skills/，并以白名单启用——只有 bundle 里的 skill 可被发现，机器上的其他 skill 不受影响。skill 的 allowed-tools 约束保持生效。

MCP servers

bundle 的 mcp/servers.json 支持 stdio（command/args/env）与 http / sse（type/url/headers）。加载时 ${ENV:...} 引用被解析为真实值后注入 server 配置——包括传递给 stdio 子进程的环境变量。

jsonc · mcp/servers.json（导出后的样子）
{
  "servers": {
    "my-api": {
      "command": "node",
      "args": ["./mcp-server.mjs"],
      "env": { "API_TOKEN": "${ENV:API_TOKEN}" }   // 值不进包
    },
    "remote": {
      "type": "http",
      "url": "https://mcp.example.com/mcp",
      "headers": { "Authorization": "${ENV:AUTH_HEADER}" }
    }
  }
}

会话与续接

会话状态持久化在 workspace 内，与机器上的其他会话完全隔离：

workspace 布局
{workspace}/
  .deepthink-sdk/
    session.json      # sessionId（resume 凭据）
    claude/           # 会话 transcript（隔离的 CLAUDE_CONFIG_DIR）
  .claude/skills/     # bundle 内联 skill 的装配点
  memory/             # memory_* 工具的日期记忆
  …你的产物
  • 跨回合：同一 Session 内 send() 自动携带上下文。
  • 跨进程：同 workspace 的新 Agent 实例自动 resume 上一轮会话。
  • 开新对话：agent.resetSession()（只清会话状态，不动你的文件）。

错误与排查

报错原因处理
missing required secrets: ${ENV:…} bundle 声明的必需密钥无法解析 通过 secrets 选项或环境变量提供，报错里列出了全部缺失项
bundle integrity check failed: contentHash mismatch… bundle 文件被改动过（哪怕一个字节） 重新导出；调试期可 skipHashCheck: true
invalid bundle: manifest.json missing 不是合法 bundle（zip 结构不对） 确认传的是「导出 SDK Bundle」产物
unsupported schemaVersion bundle 版本比 SDK 新 升级 @deepthink/agent-sdk
web_search unavailable… 未配置搜索凭据 给 createToolsServer 传 webSearch，或让 agent 改用 web_fetch
claude CLI 不可执行 / ENOEXEC npm install 脚本被拦截，CLI 是 stub npm rebuild @anthropic-ai/claude-code 后重试
返回值里的错误 RunResult.error 是回合级失败（上游返回非 success），SDK 不会抛异常——检查它再使用 text。

常见问题

为什么回复里没有我预设的人设？

bundle 的 prompts/system.md 就是最终 system prompt（导出时固化）。如果导出后又在 Agent Studio 改了 prompt，需要重新导出 bundle。

可以让 agent 使用机器上的其他 skill / MCP 吗？

bundle 的 skill 与 MCP 是白名单语义，bundle 外的不可见。需要叠加时用 extraMcpServers 显式声明。

并发跑多个 agent？

每个 Agent 实例用独立 workspace 即可并行；同一 workspace 的多个实例不要并发写（会话状态会互相覆盖）。

怎么观察 agent 在干什么？

用 onEvent。tool_use_start 带工具名与入参摘要，status 带终态与 token 用量。

Android 与版本

Android / 移动端

bundle 是纯数据，可直接打进 Android 应用（assets 或首启下载），由嵌入式 Node 运行时 + 本 SDK 执行。两个注意点：stdio 型 MCP 需纯 JS 实现（设备上没有任意系统二进制）；manifest 的 runtime.mcpDeps 字段声明了各 MCP 的依赖形态，供移动环境过滤。

版本与兼容

  • SDK 遵循 semver；@anthropic-ai/claude-agent-sdk 在包内锁定版本，不跟随 latest 漂移。
  • bundle 的 manifest.schemaVersion 当前为 1；加载器拒绝更高版本并提示升级 SDK。
  • StreamEvent 类型与 DeepThink 平台共用同一真相源，平台侧的事件语义变更会随 SDK 版本说明。
DeepThink Agent SDK · 本手册对应 SDK 0.1.x / AgentBundle schemaVersion 1。示例代码可直接复制运行；bundle 由 Agent Studio「导出 SDK Bundle」产出。
